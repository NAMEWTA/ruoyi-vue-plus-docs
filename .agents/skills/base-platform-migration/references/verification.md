# 验证矩阵

先运行技能格式校验和脚本测试，再按项目实际命令运行前端架构检查、lint、typecheck、单元、构建、Playwright E2E 与后端 Maven 测试、组合构建和发布契约。品牌扫描只报告目标第一方残留，第三方许可证/坐标列入允许清单。

浏览器必须从实际菜单生成清单并点击验证登录、注册、退出、查询/重置、增删改、弹窗、权限、通知、流程、文件、系统、监控、任务、资料和 demo；只打开 URL 或读取标题不算通过。记录 `passed|failed|skipped|not-run|not-applicable`、控制台错误、修复和重测证据。容器 running 不等于 healthy，代码版本和部署版本分开记录。
