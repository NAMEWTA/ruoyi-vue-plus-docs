## Implementation

`ThirdHttpClientFactory` centralizes JDK client connection/read timeouts, redirect policy, and Spring `RestClient` conversion; a loopback contract proves typed `@HttpExchange` clients reuse that transport. Dynamic metadata calls use the fixed gateway pipeline. Provider adapters are selected by a duplicate-checked registry with provider-owned endpoint hook validation; endpoint `adapter_code` cannot select an unowned implementation, and adapters may explicitly limit supported endpoint codes. Runtime validation re-applies endpoint method/path/mode/schema, adapter code, and server-controlled header rules on every snapshot read; safe endpoint header overrides are merged between Provider shared headers and credentials. Each physical send enters a recorder start/finish hook with bounded sanitized headers, request/response bodies, and relative path. The final implementation keeps the layered chain intact and exposes persistence, crypto, resilience, configuration, and observability through ports instead of adapter-to-DAO imports.
