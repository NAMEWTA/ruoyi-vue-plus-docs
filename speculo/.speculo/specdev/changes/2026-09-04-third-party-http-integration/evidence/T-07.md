## Implementation

`ThirdHttpClientFactory` centralizes JDK client connection/read timeouts, redirect policy, and Spring `RestClient` conversion. Dynamic metadata calls use the fixed gateway pipeline; fixed typed integrations may use the `@HttpExchange` marker. Provider adapters are selected by a duplicate-checked registry and may explicitly prepare/map requests. Runtime validation re-applies endpoint method/path/mode/schema and server-controlled header rules on every snapshot read; safe endpoint header overrides are merged between Provider shared headers and credentials. The final implementation keeps the layered chain intact and exposes persistence, crypto, resilience, configuration, and observability through ports instead of adapter-to-DAO imports.
